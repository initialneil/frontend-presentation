# Speaker Notes

Narration for the deck. This file is the single source of truth — `present.py`
serves it live, the notes window reads it, press **R** to reload after an edit.

Format: under `### Slices`, one numbered item per deck page, each followed by an
indented ```fenced``` block. **Bold** marks a keyword (shows bold in the notes
view); `[bracketed cues]` and `todo:` lines read as stage directions. Slice N
maps 1:1 to deck page N — keep them in lockstep when you add or remove slides.

### Slices
1. Title [open]
	```
	Open with the **one promise** of the talk. Say your name, then the title. Pause.
	```
2. One idea per slide [setup]
	```
	The rule for the whole deck: **one idea per slide**, in plain words. Lead with the **keyword**. Big type so the back row reads it. The script lives **here**, in the notes, not on the slide.
	```
3. Build in steps
	```
	Use an **in-slide build** when beats should land one at a time: press to reveal the next **step** without changing slides. `[press → three times, then once more to move on]`
	```
4. Close [thank you]
	```
	Land the **takeaway**, then invite **questions**. Stop talking.
	```
